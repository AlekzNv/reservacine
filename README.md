# Reserva de Asientos - Sala de Cine

**Estudiante:** Duffer Alejandro Ojeda Utreras

**Objetivo del programa:**
Este programa en Python gestiona la reserva de asientos para una sala de cine pequeña de 12 asientos organizados en 3 filas y 4 columnas. El sistema permite seleccionar un asiento mediante sus coordenadas de fila y columna, registra la reserva cambiando el estado de 0 a 1, y muestra en pantalla la matriz bidimensional actualizada utilizando bucles anidados.

**Cómo ejecutarlo:**
1. Asegúrese de tener Python instalado en su sistema.
2. Abra una terminal o línea de comandos.
3. Navegue hasta el directorio donde se encuentra el archivo `reserva_cine.py`.
4. Ejecute el comando: `python reserva_cine.py`
5. Ingrese los números de fila (0-2) y columna (0-3) cuando el programa lo solicite.
